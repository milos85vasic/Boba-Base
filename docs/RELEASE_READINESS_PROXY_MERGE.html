4. Honest capability boundaries

  • RuTracker search returns HTTP 403 with Cloudflare challenge markers from the current host path (BOB-172). Login is CAPTCHA-gated (BOB-008).
  • Kinozal search is unreachable from this host: kinozal.tv resolves to 127.0.0.1; kinozal.guru serves a Cloudflare challenge (BOB-235).
  • IPTorrents downloads are freeleech-only by policy; non-freeleech results are refused by the deduplicator.
  • VPN-egress routing is implemented and unit-tested, but end-to-end verification requires an operator-provisioned VPN host (BOB-065).
