The regression

download-proxy/src/api/routes.py’s stream_theme endpoint (GET /theme/stream) was decorated with @_rl("sse_stream") in commit 1ef4246 (BOB-167), which added the SSE route to slowapi’s rate-limit registry without adding it to BOB-129’s hand-curated _RESPONSE_RETURNING_EXEMPTIONS allowlist in tests/unit/test_bob129_slowapi_response_contract.py.

BOB-129’s contract test (TestDecoratedEndpointContract::test_every_decorated_endpoint_declares_response_or_is_exempt) asserts that every slowapi-decorated endpoint either declares a response: Response parameter, or is a reviewed exemption proven to have exactly one return, always yielding a Response subclass, with every other exit path raising HTTPException (which propagates before slowapi’s headers_enabled=True header-injection code ever runs). stream_theme satisfies that shape but was never added to the exemption set, so the test failed.

Independent root-cause re-verification (before applying any fix)

I independently re-read stream_theme’s full body in download-proxy/src/api/routes.py (lines 162–260) rather than trusting the conductor’s claim on its own, per this project’s §11.4.6/§11.4.102 investigate-before-fix mandate.

Confirmed by direct inspection + a structural grep over the function’s line range:

$ awk 'NR==162,NR==260 {print NR": "$0}' download-proxy/src/api/routes.py | grep -nE "return|raise|HTTPException"

Two things had to be checked carefully, not assumed:

  1. The raise hit at line 211 is prose inside a docstring (“re-raised by the helper”), not executable code — confirmed by reading the surrounding lines. There is no raise anywhere in stream_theme’s actual body.
  2. The return at line 241 belongs to the nested async def gen(): generator function, not to the outer stream_theme route-handler function. Python scopes a return to its own enclosing function; gen() is a separate function object whose return just stops that generator’s async iteration — it does not touch stream_theme’s control flow, and it is not the value FastAPI/slowapi wrap as the route’s response. The route handler stream_theme itself has exactly ONE return statement — line 253, return StreamingResponse(gen(), media_type=..., headers={...}) — and it is unconditional (no branch, no raise precedes or competes with it at the outer-function level).

This is genuinely the same shape as the already-exempted search_stream (download-proxy/src/api/routes.py:1046), whose body has multiple raise HTTPException(...) early-exit paths (404 not found, 403 invalid token, etc.) and exactly one terminal return SSEHandler.create_streaming_response(...) — a StreamingResponse subclass returned directly, same as stream_theme.

Verdict: independent root-cause verification agrees with the conductor’s claim in full. No discrepancy found.
