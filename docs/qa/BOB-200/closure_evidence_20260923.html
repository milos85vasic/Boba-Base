BOB-200 closure evidence — 2026-09-23

Defect

cm_dangerous_combination_fail_closed.sh built its scan file list via find(1) piped through a process substitution that silently discarded find’s own exit status — a permission-denied/resource-exhausted find failure produced an empty file list, read as “no files in scope” → honest topology SKIP → exit 0, indistinguishable from a genuinely clean corpus (§11.4.201(6) false-null).

Fix

Replaced the process-substitution mapfile -d '' -t files < <(find ...) with a scratch-file capture: find ... > "$find_scratch"; find_rc=$? checked explicitly before reading. A non-zero find_rc is now refused (exit 1, “scan enumeration failed: find exited N”), distinct from the genuine “find succeeded, zero files” honest SKIP path (unchanged, exit 0).
